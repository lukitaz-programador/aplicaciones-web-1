1. FICHA DE NEGOCIO MÍNIMA

Nombre del negocio:
Sísifo Gym.

Objetivo del negocio:
Digitalizar la gestión de las clases semanales, permitiendo a los clientes consultar horarios, reservar cupos en tiempo real y comprar o renovar sus pases mensuales de manera online.

El gimnasio obtiene ingresos principalmente mediante la venta y renovación de pases mensuales y otros planes de entrenamiento, utilizando la plataforma como canal digital para facilitar estas operaciones.

4. REQUERIMIENTOS FUNCIONALES DEL FRONTEND

RF-01 — Consultar horarios:
El sistema debe permitir visualizar la grilla semanal de clases, mostrando día, horario, disciplina, instructor y cupos disponibles.

RF-02 — Consultar disponibilidad:
El sistema debe mostrar en tiempo real la cantidad de cupos disponibles para cada clase antes de realizar una reserva.

RF-03 — Reservar una clase:
El sistema debe permitir al usuario seleccionar una clase disponible y confirmar la reserva desde la interfaz web.

RF-04 — Cancelar una reserva:
El sistema debe permitir al usuario cancelar una reserva previamente realizada, siempre que se encuentre dentro del plazo establecido por el gimnasio.

RF-05 — Comprar o renovar pase:
El sistema debe permitir seleccionar un pase y completar el proceso de compra o renovación online.

RF-06 — Consultar estado de membresía:
El sistema debe permitir al usuario consultar el estado de su membresía, incluyendo plan actual, fecha de vencimiento y días restantes.

Estos requerimientos permiten cumplir directamente con las historias de usuario planteadas y con los objetivos principales del negocio.

8. CONCEPTOS DE ARQUITECTURA WEB

MPA (Multi-Page Application):
Aplicación web en la que cada sección o página requiere cargar un nuevo documento HTML desde el servidor al navegar.

SPA (Single-Page Application):
Aplicación web que carga una página inicial y actualiza dinámicamente su contenido mediante JavaScript, evitando recargas completas al navegar entre secciones.

SSR (Server-Side Rendering):
El servidor genera el HTML de la página antes de enviarlo al navegador. Esto permite que el contenido principal esté disponible desde la primera respuesta y puede favorecer el SEO.

CSR (Client-Side Rendering):
El navegador recibe una estructura inicial y utiliza JavaScript para generar, cargar y actualizar dinámicamente el contenido de la aplicación.

Cliente:
Es el software utilizado por el usuario para acceder a la aplicación, generalmente un navegador web como Chrome, Firefox o Edge.

Servidor:
Es el sistema que recibe las solicitudes del cliente, procesa la información y devuelve respuestas, datos o recursos.

Comunicación Cliente-Servidor:
El cliente realiza solicitudes al servidor y este responde con los recursos o información solicitados. Esta comunicación permite que el usuario interactúe con las funcionalidades de la aplicación.


9. PROTOCOLOS DE COMUNICACIÓN

HTTP:
Protocolo utilizado para la comunicación entre clientes y servidores web. Permite enviar solicitudes y recibir respuestas, como páginas HTML, imágenes, archivos y datos.

HTTPS:
Versión segura de HTTP que utiliza cifrado TLS para proteger la información transmitida entre el cliente y el servidor.


10. SEO Y GEO

SEO (Search Engine Optimization):
Conjunto de técnicas utilizadas para mejorar la visibilidad y el posicionamiento de un sitio web en motores de búsqueda como Google. Incluye aspectos como contenido, estructura HTML, velocidad de carga, accesibilidad y palabras clave.

GEO (Generative Engine Optimization):
Conjunto de prácticas orientadas a facilitar que los sistemas de inteligencia artificial y motores de búsqueda generativos comprendan, interpreten y utilicen el contenido de un sitio web. Busca presentar información clara, estructurada, relevante y confiable.


11. BOCETO, WIREFRAME Y MOCKUP

Boceto:
Representación inicial y rápida de una idea. Permite definir de manera sencilla la distribución general de los elementos de una interfaz.

Wireframe:
Esquema estructural de una página que representa la ubicación, jerarquía y distribución de sus elementos sin centrarse en colores, imágenes o detalles visuales.

Mockup:
Representación visual más completa y cercana al diseño final. Incluye elementos como colores, tipografías, imágenes, botones y otros componentes de la interfaz.
